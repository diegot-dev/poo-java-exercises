# Guía de Ejercicios - Semana 02

## BUCLES: (bucles/ex0X.java)

### Ejercicio 1:
* **Descripción:** Diseñe un programa que imprima y sume 20 términos de la siguiente serie: 3, 9, 15, 21, 27, ...

### Ejercicio 2:
* **Descripción:** Diseñe un programa que imprima y sume 15 términos de la siguiente serie: 160, 156, 152, 148, 144, ...

## RECURSIVIDAD 1: (recursividad/ex0X.java)
### Ejercicio 1:
* **Descripción:** Desarrolle un programa en Java que permita calcular la potencia de un número utilizando un
método recursivo.

### Ejercicio 2:
* **Descripción:**  Desarrolle un programa en Java que permita determinar la cantidad de dígitos que contiene un
número entero utilizando un método recursivo.

### Ejercicio 3:
* **Descripción:** Desarrolle un programa en Java que permita calcular la factorial de un número entero utilizando
un método recursivo.

### Ejercicio 4:
* **Descripción:** Desarrolle un programa en Java que permita calcular la suma de todos los dígitos de un número
entero utilizando un método recursivo.

## RECUSIVIDAD 2: (recursividad/case0X.java)

### CASO 1: Contar ventas hasta llegar a meta
* **Descripción:** Una tienda vende 20 soles por cada venta. Crea un método recursivo que calcule cuántas ventas necesita para alcanzar una meta de dinero.

### CASO 2: Tabla de Conversión (Kilogramos a Libras)
* **Descripción:** Una tienda registra sus ventas diarias manualmente.
* Crea un método recursivo que reciba:
    - Un número n de días
    - Un monto de venta por día (simulado)

### CASO 3: Estadísticas Antropométricas en Educación Inicial
* **Descripción:**  Una tienda vende un producto de precio fijo.
Crea un método recursivo que reciba la cantidad de productos, precio unitario y calcule el total
a pagar.
