## 💻 Guía de Instalación y Ejecución

Sigue estos pasos para clonar y ejecutar el proyecto localmente en tu computadora:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/diegot-dev/poo-java-exercises.git
   ```

2. **Abrir en VS Code:**
   ```bash
   cd poo-java-exercises
   code .
   ```

3. **Ejecutar un ejercicio:**
   - Abre cualquier archivo `.java` dentro de `src/semanaXX/`.
   - Presiona el botón **Run** que aparece encima de la función `public static void main(...)` o presiona `F5`.
